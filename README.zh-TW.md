### 產品簡介

AnythingLLM 是一套全方位的 AI 應用程式，讓你打造私有、功能完整的 ChatGPT，不必在能力上妥協。接上你慣用的本機或雲端大型語言模型，把文件匯入，幾分鐘內就能開始對話。裝好就能用內建的智慧代理人、多使用者、向量資料庫與文件處理流程，不必再額外設定。

AnythingLLM 也支援多位使用者。你可以分別控制每個人能做什麼、看到什麼，同時不犧牲這套執行個體的安全與隱私，也不動到你的智慧財產。

### 怎麼開始

依你的用法選一種即可。下面各節有完整說明；指令與連結都跟英文原文相同。

- **桌面版：**到 [下載頁](https://anythingllm.com/download) 安裝 Mac、Windows 或 Linux 版，裝好就能用。
- **自己架一台：**用下方「自行架設」的 Docker 或雲端按鈕。Docker 的操作說明在 [docker/HOW_TO_USE_DOCKER.md](./docker/HOW_TO_USE_DOCKER.md)。不想用 Docker，看 [不透過 Docker 架設正式環境](./BARE_METAL.md)。
- **改程式、在本機開發：**在儲存庫根目錄依序執行 `yarn setup`、`yarn dev:server`、`yarn dev:frontend`、`yarn dev:collector`。步驟說明見「開發時怎麼跑」。

## AnythingLLM 的特色

- [內建的本機 LLM 引擎](/docker/HOW_TO_USE_DOCKER.md#built-in-llm-engine-optional)：不用額外設定，就能在 CPU 或 GPU 上跑本機模型（NVIDIA 走 CUDA，AMD 與 Intel 走 Vulkan）。底層是 [Lemonade](https://lemonade-server.ai) 與 [llama.cpp](https://github.com/ggml-org/llama.cpp)。
- [動態模型路由](https://docs.anythingllm.com/model-router/overview)：依照你訂的規則，自動把對話送到最適合的提供者與模型。
- [自動記憶，以及你自己管理的記憶](https://docs.anythingllm.com/features/memories)：讓模型記住你或這個工作區的重要資訊。
- [排程工作](https://docs.anythingllm.com/scheduled-jobs/overview)：用 cron 排程重複執行工作或提示詞，並保有完整的智慧代理人能力。
- [智慧技能挑選](https://docs.anythingllm.com/agent/intelligent-tool-selection)：可以啟用**不限數量**的工具，同時把每次查詢的 token 用量最多減少 80%。
- [無程式碼的 AI 代理人建構器](https://docs.anythingllm.com/agent-flows/overview)
- [相容 MCP](https://docs.anythingllm.com/mcp-compatibility/overview)
- [多模態支援（閉源與開源 LLM 都可以）](https://docs.anythingllm.com/features/language-models)
- [自訂 AI 代理人](https://docs.anythingllm.com/agent/custom/introduction)
- 👤 多使用者執行個體與權限控管 _僅 Docker 版_
- 🎨 [自訂配色與白標](https://docs.anythingllm.com/features/branding)：可以選內建配色（例如 True Dark），或用自己的品牌色做一套，套用給這個執行個體上的所有人。_僅 Docker 版_
- 🦾 工作區裡的智慧代理人（可以瀏覽網頁等）
- 💬 [可嵌進網站的自訂聊天小工具](https://github.com/Mintplex-Labs/anythingllm-embed/blob/main/README.md) _僅 Docker 版_
- 📖 支援多種文件格式（PDF、TXT、DOCX 等）
- 聊天介面直覺，可以直接拖放上傳，回答也會附上來源。
- 可以部署到各種雲端，直接當正式環境用。
- 相容各種常見的[閉源與開源 LLM 提供者](#supported-llms-embedder-models-speech-models-and-vector-databases)。
- 針對大量文件做了內建最佳化，成本比其他聊天介面低，回應也比較快。
- 提供完整的開發者 API，方便自己接上其他系統。
- 還有更多。幾分鐘就能裝好，實際用一次就知道。

### 技術架構

這個單一儲存庫（monorepo）分成六個主要部分：

- `frontend`：用 Vite 與 React 做的前端，用來建立與管理要提供給 LLM 的內容。
- `server`：Node.js Express 伺服器，負責所有互動，也處理向量資料庫與 LLM 的溝通。
- `collector`：Node.js Express 伺服器，處理並解析從介面送來的文件。
- `docker`：Docker 說明、建置流程，以及從原始碼建置的資訊。
- `embed`：子模組，用來產生與建立[網頁嵌入小工具](https://github.com/Mintplex-Labs/anythingllm-embed)。
- `browser-extension`：子模組，[Chrome 瀏覽器擴充功能](https://github.com/Mintplex-Labs/anythingllm-extension)。

## 開發時怎麼跑

- `yarn setup`：在儲存庫根目錄執行，把各個部分需要的 `.env` 檔準備好。
  - 先把這些檔案填完再繼續。`server/.env.development` 一定要填，否則後面會不正常。
- `yarn dev:server`：在儲存庫根目錄執行，在本機啟動伺服器。
- `yarn dev:frontend`：在儲存庫根目錄執行，在本機啟動前端。
- `yarn dev:collector`：在儲存庫根目錄執行，接著啟動文件收集器。

## 遙測與隱私

Mintplex Labs Inc 的 AnythingLLM 內含遙測功能，會收集匿名的使用資訊。

<details>
<summary><kbd>AnythingLLM 的遙測與隱私</kbd></summary>

### 為什麼要收集？

我們用這些資訊了解 AnythingLLM 怎麼被使用，以便安排新功能與錯誤修正的優先順序，並改善效能與穩定性。

### 如何關閉

在伺服器或 Docker 的 .env 把 `DISABLE_TELEMETRY` 設成 `"true"`，就不會再送遙測。也可以在應用程式裡關：側邊欄的 `Privacy`（繁體中文介面顯示為「隱私與資料」），把遙測關掉。

### 我們明確記錄哪些東西？

我們只記錄有助於產品與路線規劃的使用細節，具體是：

- 你的安裝類型（Docker 或桌面版）

- 文件被新增或移除的時候。不會有文件本身的任何資訊，只有「這件事發生了」。這讓我們知道使用情形。

- 正在使用的向量資料庫類型。那個提供者有更新時，我們比較知道該先調整什麼。

- 正在使用的 LLM 提供者與模型標籤。提供者、模型，或兩者的組合有更新時（例如推理模型對上一般模型、多模態模型），我們比較知道該先調整什麼。

- 送出對話的時候。這是最常發生的「事件」，讓我們知道所有安裝每天大概有多活躍。同樣只送出**事件**本身，我們拿不到對話的性質或內容。

這些說法都可以核對：搜尋程式碼裡所有呼叫 `Telemetry.sendTelemetry` 的地方。有開啟的話，這些事件也會寫進輸出日誌，你可以看見實際送出的資料。**不會收集 IP 或其他可識別身分的資訊。** 遙測服務是 [PostHog](https://posthog.com/)，一套開源的遙測收集服務。

我們很重視隱私。希望你理解：我們想知道這個工具怎麼被使用，又不想用跳出的問卷來打擾你，才能做出值得用的東西。這些匿名資料**絕不會**再交給第三方。

[在原始碼裡查看所有遙測事件](https://github.com/search?q=repo%3AMintplex-Labs%2Fanything-llm%20.sendTelemetry(&type=code)

### 其他對外連線

就算關掉遙測，你還是可能看到連往下列服務的對外連線：

- 如果使用外部工具、LLM、嵌入模型或向量資料庫，仍會連到對應的服務提供者。
- `cdn.anythingllm.com`：從我們的鏡像 CDN 下載模型。這不在遙測範圍內，對人在 VPN 受限地區的使用者其實有幫助。
- `github/githubusercontent.com`：會從這些網域下載一些純文字檔，用來快取上下文視窗。

簡單說，遙測關掉之後我們就不會收集任何資料。不過依你的設定，仍可能有對外連線，那些連線適用各服務提供者自己的服務條款。
